# 许家印桌宠

macOS 透明桌面人物，使用提供的人物 PNG 和视频中的完整音频。

## 邦友跳舞
右键选择 **邦友跳舞**，形象会切换为提供的玩偶图片。单击开始播放新视频中的音乐（约 3 分 7 秒），再次单击暂停，再次单击继续；音乐结束后循环。再次选择“邦友跳舞”可取消此模式并切回许家印。

音乐播放时，更新后的孙宇晨（SunPet）、好事桌宠、雷军和余承东桌宠会跟随相同节拍上下压缩跳动。只带动已经打开的桌宠，不自动启动其他应用。暂停、退出或切回许家印时停止跟跳；意外关闭后最多约 1.5 秒自动恢复。桌宠自身原有点击交互继续可用。

原音频和邦友音乐分别记住播放进度，音量共用。右键“从头开始播放音频”对当前模式生效。

## 使用
- 单击人物：播放；再次单击：暂停；再单击：从暂停位置继续。
- 音频播放到结尾会自动从头循环。
- 播放时切换为戴墨镜、拿扇子的形象，并按音轨检测到的每个节拍以相同幅度上下压缩、回弹；暂停时切回原形象并保持静止。
- 按住人物拖动：移动位置，不会切换播放。
- 右键人物 → **从头开始播放音频**：立即回到开头播放。
- 右键或菜单栏“许”：调整音量和头像大小、移回当前屏幕左下角、暂停/继续或关闭桌宠。
- 正常退出时保存播放进度和位置，重新打开后点击继续。

## 安装
在 GitHub 的 Releases 页面下载“许家印桌宠-安装包.zip”，解压后将“许家印桌宠.app”放进“应用程序”文件夹，双击打开。若还要让其他四个桌宠同步跳舞，需要在本机安装支持联动的更新版应用；本仓库只提供许家印桌宠。适用于 Apple Silicon Mac，macOS 13 及以上；已在当前电脑编译。启动时不会自动播放。

## 输入输出示例
点击人物 → 视频音轨开始播放并伴随跳动；中途点击 → 暂停并静止；再点击 → 继续原来的进度。右键选择从头播放 → 进度回到 0。

节奏数据保存在 Assets/beats.json，更换音轨后可运行 `swift Tools/analyze-rhythm.swift Assets/audio.m4a Assets/beats.json` 重新分析。

## 构建
安装 Apple Command Line Tools 后，在此目录运行 `./build.sh`。素材位于 Assets，程序位于 Sources/main.swift 和 Sources/SharedDance.swift。使用系统 AppKit 与 AVFoundation，无需联网运行。
